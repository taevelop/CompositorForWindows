# 선택·크롭 이식 상태

2026-10-06: 사각형·타원 선택과 편집 범위 제한을 구현했다. 선택·크롭 영역 전체 완료는 아니다.

## 현재 사용 가능한 기능

- 왼쪽 도구의 사각형 선택(M), 타원 선택(Shift+M).
- 옵션 바의 New / Add / Subtract, Smooth edges. 누르기 전 Shift는 추가, Alt는 빼기이며 드래그 중 Shift는 정사각형/원 제한이다.
- Select 메뉴의 전체 선택(Ctrl+A), 해제(Ctrl+D), 반전, 선택 픽셀 지우기(Delete).
- 화면 배율에 관계없이 일정한 점선 윤곽. 빈 선택은 상태 표시줄에 편집 차단으로 표시한다.
- 선택 안쪽에만 브러시·지우개·마스크 브러시·9종 픽셀 색상 조정·기존 밝기/대비/채도를 적용한다.
- 한 번의 선택 드래그는 한 번의 Undo다. Esc, 캡처 상실, 도구 전환은 미완료 선택을 취소한다. 다른 마우스 버튼으로 현재 드래그를 끝내지 않는다.
- Delete는 선택이 있으면 선택 픽셀/마스크 농도를 지우고, 선택이 없으면 기존 레이어 삭제 동작을 유지한다. 명시적 빈 선택은 아무 픽셀도 지우지 않는다.

## 원본 대조 및 구현

원본 macOS/Compositor/Document 아래 Selection.swift, SelectionEdits.swift, EditorSession.swift, Crop.swift를 기준으로 했다.

- 선택은 문서 좌표의 불변 SVG 윤곽, 채움 규칙, 안티앨리어싱, 페더 값이다. 문서 모델은 Skia 타입을 참조하지 않는다.
- null은 편집 제한 없음, 빈 윤곽은 아무것도 선택하지 않음이다. 서로 대체하지 않는다.
- 선택은 원본처럼 Undo 문서 상태에 포함하지만 .comp 파일에는 저장하지 않는다. 저장 후 재열면 선택은 해제되고 변경한 픽셀은 유지된다.
- 추가/빼기는 캔버스와 교차한 새 윤곽으로 연산하고 페더를 초기화한다. 구멍의 채움 규칙은 SVG 왕복에서도 보존한다.
- 선택 커버리지는 윤곽 주변의 제한된 영역에만 생성한다. 페더는 sigma = 반경/2의 Gaussian이며 캔버스 경계는 clamp한다.
- 회전·뒤집기·크기 변경된 레이어도 소스 픽셀 중심을 문서 좌표로 변환해 선택 농도를 샘플링한다.
- 브러시는 원본 픽셀과 누적 스트로크 결과를 선택 농도로 혼합한다. 매 포인터 이벤트의 직전 미리보기에 다시 곱하지 않으므로 경계 농도가 누적되지 않는다. 타일별 선택 농도는 스트로크 동안 재사용한다.
- 선택 픽셀 지우기와 조정은 256 MiB Undo 보존 제한을 확인한다. 선택 점선은 캔버스 오버레이로 출력 이미지에 들어가지 않는다.

## 검증

- ./build.ps1 -Test: Release 경고/오류 0, 377개 테스트 통과, 실제 WPF 스모크 통과.
- 선택 테스트: 구멍/합집합/반전, 타원·다각형, 페더/확장/축소/이동 연산, 회전 좌표, 빈 선택, 타일 공유, 브러시/지우개 누적과 마스크 농도, Undo/Redo/취소, 저장 후 선택 제외와 픽셀 보존.
- WPF: 사각형·타원 빼기, 버튼 소유권/취소, 브러시 제한, 지우기/Undo, 픽셀 조정 제한, 전체 선택/반전/해제. 6개 도구의 제목 및 캔버스 위치가 일정함을 확인했다.
- artifacts/ui-smoke.selection.png 화면을 직접 확인해 선택 옵션의 글자 대비를 보완했다. 테마는 기존 차분한 블루를 사용한다.
- 전체 테스트 호스트가 한 차례 비정상 종료했다. 충돌 진단을 켠 선택 테스트 17개 및 전체 376개 재실행에서 재현되지 않았고, 저장 테스트 추가 후 전체 377개와 WPF도 통과했다. 원인 확인 없이 영구 해결로 간주하지 않는다.
