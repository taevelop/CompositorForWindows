# 선택·크롭 이식 상태

2026-10-06: 사각형·타원·자유/다각형 올가미, 선택 윤곽 이동, 페더·확장·축소 및 편집 범위 제한을 구현했다. 선택·크롭 영역 전체 완료는 아니다.

## 현재 사용 가능한 기능

- 왼쪽 도구의 사각형 선택(M), 타원 선택(Shift+M), 자유 올가미(L), 다각형 올가미(Shift+L). 자유 올가미는 드래그 중 열린 윤곽을 보여주고 놓으면 닫아 확정한다.
- 다각형 올가미는 클릭마다 꼭짓점을 추가한다. Enter, 더블클릭, 첫 꼭짓점의 화면상 8px 이내 클릭으로 닫는다. Backspace/Delete는 마지막 점을 제거하며 Esc는 초안을 취소한다.
- 옵션 바의 New / Add / Subtract, Smooth edges. 누르기 전 Shift는 추가, Alt는 빼기다. Shift 추가로 시작한 경우 Shift를 놓았다가 다시 눌러야 정사각형/원 제한이 적용된다. From center는 중심 기준 박스를 만든다.
- Select 메뉴의 전체 선택(Ctrl+A), 해제(Ctrl+D), 반전, 선택 픽셀 지우기(Delete), Feather / Expand / Contract 편집창.
- New 모드로 선택 내부를 드래그하면 윤곽만 이동한다. Shift는 한 축으로 제한한다. 선택 도구의 방향키는 1px, Shift+방향키는 10px 이동한다. 캔버스 밖으로 나가도 윤곽을 잘라내지 않는다.
- 페더·확장·축소 창은 슬라이더/정밀 수치, 선택 농도 미리보기, 비교, 취소, 단일 Undo를 제공한다. 미리보기 계산은 비동기이며 닫은 뒤 늦게 도착한 결과는 적용하지 않는다.
- 화면 배율에 관계없이 일정한 점선 윤곽. 빈 선택은 상태 표시줄에 편집 차단으로 표시한다.
- 선택 안쪽에만 브러시·지우개·마스크 브러시·9종 픽셀 색상 조정·기존 밝기/대비/채도를 적용한다.
- 한 번의 선택 드래그는 한 번의 Undo다. Esc, 캡처 상실, 도구 전환은 미완료 선택을 취소한다. 다른 마우스 버튼으로 현재 드래그를 끝내지 않는다.
- Delete는 선택이 있으면 선택 픽셀/마스크 농도를 지우고, 선택이 없으면 기존 레이어 삭제 동작을 유지한다. 명시적 빈 선택은 아무 픽셀도 지우지 않는다.

## 원본 대조 및 구현

원본 macOS/Compositor/Document 아래 Selection.swift, SelectionEdits.swift, EditorSession.swift, Crop.swift를 기준으로 했다.

- 선택은 문서 좌표의 불변 SVG 윤곽, 채움 규칙, 안티앨리어싱, 페더 값이다. 문서 모델은 Skia 타입을 참조하지 않는다.
- null은 편집 제한 없음, 빈 윤곽은 아무것도 선택하지 않음이다. 서로 대체하지 않는다.
- 선택은 원본처럼 Undo 문서 상태에 포함하지만 .comp 파일에는 저장하지 않는다. 저장 후 재열면 선택은 해제되고 변경한 픽셀은 유지된다.
- 추가/빼기는 캔버스와 교차한 새 윤곽으로 연산하고 페더를 초기화한다. 구멍의 채움 규칙은 SVG 왕복에서도 보존한다.
- 선택 커버리지는 윤곽 주변의 제한된 영역에만 생성한다. 페더는 sigma = 반경/2의 Gaussian이며 캔버스 경계는 clamp한다.
- 회전·뒤집기·크기 변경된 레이어도 소스 픽셀 중심을 문서 좌표로 변환해 선택 농도를 샘플링한다.
- 브러시는 원본 픽셀과 누적 스트로크 결과를 선택 농도로 혼합한다. 매 포인터 이벤트의 직전 미리보기에 다시 곱하지 않으므로 경계 농도가 누적되지 않는다. 타일별 선택 농도는 스트로크 동안 재사용한다.
- 선택 픽셀 지우기와 조정은 256 MiB Undo 보존 제한을 확인한다. 선택 점선은 캔버스 오버레이로 출력 이미지에 들어가지 않는다.

## 검증

- ./build.ps1 -Test: Release 경고/오류 0, 380개 테스트 통과, 실제 WPF 스모크 통과.
- 선택 테스트: 구멍/합집합/반전, 타원·다각형, 페더/확장/축소/이동 연산, 회전 좌표, 빈 선택, 타일 공유, 브러시/지우개 누적과 마스크 농도, Undo/Redo/취소, 저장 후 선택 제외와 픽셀 보존.
- WPF: 사각형·타원 빼기, 버튼 소유권/취소, 브러시 제한, 지우기/Undo, 픽셀 조정 제한, 전체 선택/반전/해제. 8개 도구의 제목 및 캔버스 위치가 일정함을 확인했다.
- artifacts/ui-smoke.selection.png 화면을 직접 확인해 선택 옵션의 글자 대비를 보완했다. 테마는 기존 차분한 블루를 사용한다.
- 전체 테스트 호스트가 한 차례 비정상 종료했다. 충돌 진단을 켠 선택 테스트 17개 및 전체 376개 재실행에서 재현되지 않았고, 저장 테스트 추가 후 전체 377개와 WPF도 통과했다. 원인 확인 없이 영구 해결로 간주하지 않는다.

## 2차 입력/수정창 검증

- 원본의 정수 픽셀 스냅, 면적 없는 클릭의 해제, New 모드의 내부 드래그/클릭 동작, Shift 추가와 정사각형 제한의 구분을 대조했다.
- 원점 밖에서 폭/높이가 0인 박스의 판정 오류를 WPF 검증으로 발견했다. Skia의 IsEmpty에만 의존하지 않고 폭/높이를 검사하며 3개 회귀 테스트를 추가했다.
- 실제 WPF에서 자유 올가미, 윤곽 이동/방향키/Undo/클릭 해제, 중심 기준 선택, 세 수정창의 미리보기/비교/확정/취소/Undo/Redo, 0반경 무변경, 취소 뒤 비동기 결과 폐기를 확인했다.
- artifacts/ui-smoke.selection.feather.png를 직접 확인해 파생 Window의 배경 스타일 누락을 수정했다. 7개 도구의 제목과 캔버스 위치 검증도 통과했다.
- 자유 올가미는 0.25px 미만 중복 지점을 건너뛰고 100,000개 꼭짓점 제한을 둔다. 긴 윤곽/큰 페더의 성능은 별도 잔여로 유지한다.

## 3차 다각형 올가미 검증

- 원본 EditorCanvas.swift의 lassoMouseDown과 Selection.swift의 꼭짓점 제거/닫기 규칙을 대조했다. Windows 단축키는 Shift+L로 직접 다각형 도구를 선택한다.
- 클릭 사이에는 문서를 바꾸지 않고 초안과 커서까지의 선을 표시한다. 닫은 윤곽과 기존 선택의 연산을 한 번의 Undo로 확정한다. 시작 시 결정한 New/Add/Subtract 모드를 유지한다.
- 마우스를 놓을 때 자체 캡처 해제는 초안을 유지한다. 다른 컨트롤에 캡처를 잃거나 창 비활성화, 도구 전환, Esc는 초안을 취소한다. 버튼을 누른 상태에서 점을 지워도 다음 클릭을 받을 수 있다.
- 실제 WPF에서 Enter, Backspace/Delete, 마지막 점 삭제, Esc, 첫 점 근처 클릭, 더블클릭, 외부 버튼 거부, 캡처 해제/상실, 도구 전환, Undo/Redo를 검증했다.
- ./build.ps1 -Test: 경고/오류 0, 기존 380개 코어 테스트 및 확장한 실제 WPF 스모크 통과. 8개 도구의 제목/캔버스 위치가 일정하다. 다각형 도구 화면 캡처도 확인했다.

## 다음 픽셀 이동의 원본 기준

SelectionEdits.swift의 PixelMove는 윤곽 이동과 별개다. 선택한 이미지 픽셀만 이동/복제하며 마스크 대상은 허용하지 않는다. 원본에는 Cmd-drag, Cmd+Option-drag 복제, Cmd-arrow가 있다. Windows에서는 Ctrl 대응을 구현할 예정이다. 빈 픽셀 범위와 0 오프셋은 변경하지 않으며 픽셀과 이동한 윤곽을 함께 한 Undo로 확정한다. BrushStroke.swift의 liftSelection/moveLifted, EditorSession+Brush.swift의 makeRasterEdit/commitRasterEdit를 대조해 변환된 레이어의 샘플링과 확장 경계를 보존해야 한다.
