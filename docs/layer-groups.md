# Windows 레이어 그룹 구현 및 검증

2026-09-23. 기존 마스크 구현 위에 그룹과 계층 패널을 추가했다. macOS 원본 소스는 수정하지 않는다.

## 사용법

- **+ Group**: 빈 그룹 생성. 그룹이 선택돼 있으면 그 안에, 일반 레이어가 선택돼 있으면 같은 부모 안에 생성한다.
- **Group**: 선택한 항목을 새 그룹으로 감싼다. 다른 항목도 넣으려면 아래 부모 이동을 사용한다. 현재 선택은 한 항목씩 지원한다.
- **+/− 펼치기 버튼**: 계층을 접거나 펼친다. 자식이 선택된 상태에서 부모를 접으면 부모를 선택한다. 접힘은 문서 수정이나 Undo를 만들지 않는다.
- **Move into a group**: 부모를 고르고 **Move here**. **Document root**는 최상위다. **Move out**은 한 단계 밖으로 이동한다. 이동된 항목은 대상 부모의 맨 위에 들어간다. 그룹을 옮기면 하위 항목도 함께 이동한다.
- **↑/↓**: 같은 부모 안에서 순서를 바꾼다. 그룹 전체도 하나의 형제 항목으로 이동한다.
- **Ungroup**: 그룹만 없애고 자식을 그 자리에 유지한다. 화면을 유지하기 위해 제거된 그룹의 표시 여부·불투명도를 직속 자식에 반영한다. 따라서 자식의 속성 숫자는 달라질 수 있다.
- **−/Delete**: 그룹과 모든 자식을 삭제한다. Undo로 계층·선택·픽셀을 복원한다.
- 그룹을 선택하고 **Move 도구**로 드래그하면 하위 레이어와 연결 마스크가 함께 이동한다. Esc·캡처 상실·창 비활성화로 취소할 수 있다.
- 그룹을 선택한 상태에서 새 레이어 또는 PNG/JPEG를 가져오면 그 그룹 안에 들어간다. 그룹에 직접 칠하거나 숨겨진 부모 아래 자식에 칠하는 입력은 거부한다.

부모를 바꾸면 새 부모의 표시·불투명도를 상속하므로 모습이 달라질 수 있다. 그룹 자체 회전·크기 변경·뒤집기, 다중 선택, 계층 드래그 앤 드롭, 그룹 마스크는 이번 구현에 포함하지 않는다. 변환이나 마스크 편집은 자식 레이어를 선택한다.

## 합성 및 저장

Mac과 같은 pass-through 방식을 사용한다. 자식을 별도 그룹 이미지로 합치지 않고 배경에 직접 합성하며, 자식의 유효 불투명도는 자기 값과 모든 부모 값의 곱이다. 예를 들어 자식 50% × 부모 50% = 25%다. 부모가 숨겨져 있으면 해당 하위 레이어도 숨긴다. 자식의 합성 모드와 마스크는 그대로 적용한다.

`isGroup`, `parentID`를 저장하고 버전 2–8 그룹을 읽는다. 그룹 불투명도는 버전 8에서만 1 이외의 값을 허용한다. 그룹의 `imageFile`은 없거나 null, 합성 모드는 Normal이어야 한다. 그룹 자체 마스크는 거부한다. 사이클·누락 부모·일반 레이어를 부모로 지정한 경우 및 64단계 초과 중첩을 거부한다. 자세한 필드는 [프로젝트 규격](project-format.md)을 참고한다.

자식의 변환은 문서 절대 좌표다. 그룹 이동은 하위 항목의 원점을 이동시키며 그룹 transform을 추가 변환 행렬로 적용하지 않는다. 파일의 배열은 같은 부모 안에서의 아래→위 순서를 정의하므로 자식이 부모 바로 뒤에 연속해 있지 않아도 지원한다. 그룹 접힘 상태는 저장하지 않는다.

저장 게시 실패 시 기존 프로젝트를 보존하는 절차와 미지원 필드 거부 정책을 유지한다. 실제 Mac 앱의 대표 문서로 양방향 호환을 확인한 것은 아니며, 원본 저장/계층 코드와 Windows 회귀 검증을 기준으로 구현했다.

## 검증

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Test
dotnet run --project Compositor.Benchmarks/Compositor.Benchmarks.csproj -c Release -- --groups artifacts/group-benchmark.json
powershell -NoProfile -ExecutionPolicy Bypass -File build.ps1 -Publish
```

- Release 빌드: 경고 0개·오류 0개. 기존 마스크 검증을 포함한 xUnit **99개 통과**.
- 비연속 파일 배열의 계층 순서, 중첩 표시·불투명도, 자식별 합성, 마스크와 Normal/Multiply/Screen 조합.
- 그룹 생성·해제·순서·부모 이동·하위 삭제, 자기/자손으로 이동 거부, 불투명/숨김 그룹 해제의 화면 보존.
- 그룹 이동 시 픽셀·마스크 공유, 원위치 이동의 no-op, 취소·Undo/Redo·선택 복원.
- 64단계 경계, 사이클·잘못된 부모 거부, 그룹 이미지/마스크/합성 모드 및 버전 제약, 저장 실패의 이전 문서 보존, PNG 출력과 합성 일치.
- 그룹 속성·부모 변경·순서·이동 후 증분 화면과 전체 합성 일치.
- 숨김 WPF: 계층 행 선택, 접기·펼치기, 중첩 그룹과 새 자식, 그룹 전체 이동/취소/Undo, 부모 이동/순서/Undo 시 선택 노출, 해제/삭제/표시와 Undo, 저장/재열기/PNG 출력, 그룹 안으로 이미지 가져오기, 그룹 직접 페인팅 및 숨겨진 자식 페인팅 거부.

결과는 `artifacts/ui-smoke.groups.json`, 화면은 `artifacts/ui-smoke.png`에 있다. self-contained win-x64 배포 실행 파일에서도 기존 안정화·마스크·그룹 검증을 모두 통과했다. 배포 결과는 `artifacts/published-group-smoke.groups.json`, 화면은 `artifacts/published-group-smoke.png`에 남겼다. 물리 마우스·펜·다중 모니터 DPI·실제 저장 중 강제 종료는 기존 수동 검증 항목으로 남는다.

## 중첩 그룹 성능

2026-09-23 00:46 UTC, Intel Core 5 210H, RAM 약 64GiB, Release CPU 경로. 서로 다른 4000×4000 이미지 6개(96MP), 최하단 마스크에 800px soft 브러시, 120회 입력 × 2스트로크, 1000×1000 Skia 뷰포트. 그룹마다 불투명도 90%, 회전 없음. 각 행은 두 스트로크 중 큰 p95·종료 값이다.

| 중첩 그룹 수 | 갱신 p95 | 스트로크 종료 | working set |
|---|---:|---:|---:|
| 0 | 26.1ms | 4.1ms | 약 1309MiB |
| 3 | 27.9ms | 2.7ms | 약 1307MiB |
| 16 | 29.4ms | 3.6ms | 약 1296MiB |

초기 p95 ≤33.3ms·종료 ≤100ms 기준을 모두 충족했다. 최초 합성은 순서대로 436/261/252ms이며, 첫 시나리오에는 초기 실행 비용이 섞여 있으므로 중첩이 최초 합성을 빠르게 한다는 뜻이 아니다. 이전 시나리오를 포함한 프로세스 최대 working set은 약 1310MiB였다.

WPF 표시 지연·실제 입력부터 화면 갱신까지의 지연은 포함하지 않는다. 수천 개 계층 행의 UI 성능, 64단계 최대 중첩의 성능, 회전된 그룹 자식의 전체 화면 재합성 성능은 별도 측정이 필요하다.
