# Lens Correction 전환

2026-10-08 연산 기반을 구현했다. native/kernels/LensPixels.c와 원본 macOS 커널 SHA-256이 같다. 고정 폭 int32 크기와 double 강도의 네이티브 ABI를 연결했다. 원본처럼 입력 범위는 -100–100, 실제 커널 강도는 distortion / 100 × 0.35다.

전체 해상도 premultiplied RGBA의 방사형 역매핑과 투명 바깥 영역의 bilinear 보간을 사용한다. 왜곡 0은 원본 참조를 반환한다. 빈 타일에 픽셀이 이동할 수 있으므로 출력 전체 격자를 재구성한다. 문서 적용은 선택 커버리지, 레이어 메타데이터·마스크 보존 및 256MiB Undo 제한을 사용한다.

양·음 최대 왜곡에 대해 별도 C# 참조 보간과 전체 바이트 일치를 확인했다. 263픽셀 너비의 타일 경계, 반투명 입력, 원본 불변, 0 왜곡 참조 공유, 잘못된 값 및 사전 취소를 검사했다.

UI와 축소 표시 전용 미리보기, Apply/Cancel/Undo/저장 왕복의 기능 검증, 4K 성능 측정은 아직 남아 있다. C 커널 호출 내부 중간 취소도 제공하지 않는다. 실제 Mac 왕복과 별도 PC 검증은 보류다. 연산 기반만으로 기능 완료나 전체 진행률 증가를 주장하지 않는다.

Release 빌드 경고/오류 0, 코어 616개 및 기존 실제 WPF 회귀 검사 통과. Lens UI 자체의 검증은 아직 아니다.
