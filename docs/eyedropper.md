# 스포이트 구현 현황

2026-10-07: 합성 색상 샘플러와 I 도구/브러시·지우개 Alt 임시 스포이트를 연결했다. 색상 비교 링과 열린 색상 선택창 샘플링은 아직 남아 있다.

원본 Document/ColorPalette.swift의 sampleCompositeColor는 화면의 체크무늬나 선택 윤곽을 제외한 보이는 레이어 합성 결과를 sRGB 단일 픽셀로 읽는다. 문서 좌표는 내림 처리하고 캔버스 밖 및 알파 0은 샘플 없음으로 처리한다. premultiplied 채널을 알파로 나누고 8비트 RGB로 반올림한다. 현재 레이어/평균 범위 선택은 이 원본 경로에 없다.

CompositeColorSampler는 화면/출력과 같은 CanvasRenderer와 1×1 출력 비트맵을 재사용한다. IDisposable로 비트맵/캔버스/렌더러 캐시를 정리한다. 조정과 효과의 내부 합성이 전체 문서 버퍼를 사용할 수 있으므로 1×1 출력이 전체 연산량이나 메모리까지 작다는 의미는 아니다. UI 연결 후 큰 문서 연속 샘플링의 지연과 메모리를 측정해야 한다.

검증: 코어 541개 및 기존 WPF 회귀 검사 통과. 소수 좌표 내림, 반투명 RGB 복원, 투명/범위 밖/NaN/무한대, 그룹 불투명도+마스크+숨긴 레이어의 전체 합성 픽셀 일치, 조정 문서 변경/원래 문서 복귀 시 캐시, 중복 Dispose 및 해제 후 호출 거부를 검사했다. 실제 Mac 색상 동등성은 보류다.

남은 연결: 색상 비교 링, 열린 색상 선택창 샘플링, 대형 문서 샘플링 지연/메모리 측정. 원본 Rendering/EditorCanvas.swift의 sampleColor는 팔레트 전경색을 갱신하며, 색상 선택창이 열렸다면 해당 선택창의 미리보기 색상만 갱신한다. 문서 픽셀/Undo는 변경하지 않아야 한다.

## 도구와 입력 연결

I 도구 또는 브러시/지우개에서 Alt+왼쪽 버튼으로 합성 색상을 전경색에 반영한다. 원본은 지우개가 브러시의 모드이므로 Windows의 별도 Eraser 도구도 Alt 샘플링을 지원한다. 누른 상태로 이동하면 연속 샘플링하며 다른 버튼이 입력을 가로채지 않는다. 선택 마스크와 무관하게 화면의 합성을 읽고, 마스크 편집 중에도 원본처럼 실제 전경색을 갱신하되 마스크 회색 농도는 바꾸지 않는다.

해제·Esc·캡처 상실·도구 전환은 입력 상태를 정리하며 마지막으로 읽은 색상을 유지한다. 문서 픽셀, 수정 상태, Undo는 바꾸지 않는다. 화면 좌표는 현재 확대/이동을 적용해 문서 좌표로 변환한다. I 및 Alt 입력은 기존 Ctrl+I 가져오기와 텍스트 입력 단축키를 유지한다. 커서는 현재 십자이며 원본 비교 링/전용 커서 완성은 후속 품질 범위다.

WPF 검사: 클릭/드래그, 투명/밖 영역의 이전 색상 보존, 버튼 조합, Alt 브러시/지우개, 취소/도구 전환, 확대/이동 좌표, 문서 스냅샷/Undo 불변성. Esc와 캡처 상실은 합성 WPF 이벤트로 검사한다. 실제 마우스·키보드 실기와 Mac 결과 비교는 대체하지 않는다.

최종 검증: 코어 541개, 확장 WPF 검사 및 I 도구 화면 정렬 확인 통과. artifacts/publish-eyedropper/Compositor.Windows.exe 생성 및 verify-portable.ps1 -Runs 1 통과. 별도 Windows/Mac 검증 보류 유지.

## 색상 비교 링

검증: 코어 541개와 WPF 회귀 통과. 두 반원 색상, 외곽선, 투명 중심, 표시 끄기, 설정 복원, 취소 후 제거를 검사하고 생성 이미지를 확인했다. 실제 다중 DPI 마우스 실기와 Mac 색상 비교는 미검증이다. 열린 색상 선택창 샘플링과 대형 문서 성능 측정은 계속 남아 있다.

## 색상 선택창 샘플링 1차

2026-10-07: 전경/배경 및 중첩 효과 색상 선택창에 Sample canvas 버튼을 연결했다. 기존 모달 창의 소유자 체인에서 실제 편집 캔버스를 찾고, 캔버스 위치에 투명 입력 창을 띄워 동일 합성 샘플러로 읽는다. 문서와 효과 미리보기는 입력 차단 상태를 유지한다. 클릭/드래그 후 해제하면 선택창의 색상만 바뀌고 Use color로 확정한다. Esc/캡처 상실은 샘플링을 취소한다. 투명 픽셀은 직전 유효 색상을 유지한다.

코어 541개와 WPF 회귀 통과. 실제 중첩 ShowDialog 흐름에서 확대/이동 좌표, 투명 픽셀, 샘플 확정/취소, 전경색·문서·Undo 불변성을 검사했다. 물리 입력은 합성 호출로 대체 검증하지 않았다. 원본의 열린 선택창 연속 미리보기 및 비교 링은 이 경로에 아직 연결하지 않았으며, 다중 DPI/모니터 위치 및 실제 마우스 검증과 함께 후속 범위다. 이 단계로 색상 선택창 샘플링 전체가 완료된 것으로 처리하지 않는다.
