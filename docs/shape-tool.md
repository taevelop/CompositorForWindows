# 도형 도구 전환

2026-10-07. 원본 macOS/Compositor/Document/ShapeTool.swift, UI/ShapeControls.swift 및 ProjectStore.swift를 대조한다.

## 원본 범위

- Rectangle / Ellipse / Line. 사각형 반경, 선 두께·둥근 끝, 전경색을 사용한다.
- Shift는 정사각형/원 또는 선의 45도 각도, Option은 중심 기준 드래그다. U/Shift-U/Tab 도형 종류 전환을 지원한다.
- 새 레이어를 추가하며 선택은 유지하고 한 번의 Undo다.
- shape 스타일과 PNG를 함께 저장한다. 다른 도구로 픽셀을 변경하면 liveShape가 해제된다.
- 크기를 바꿀 때 다시 래스터화하며 반경·선 두께를 문서 픽셀 기준으로 유지한다. 연결 마스크의 좌표 보존도 필요하다.

## 현재 구현: 스타일·래스터 기반

LayerShapeStyle과 ShapeRaster.Create를 추가했다. 색상은 원본처럼 0–1 실수, 선 끝점은 박스 비율이며 선의 누락된 끝점은 반 두께만큼 안쪽으로 기본 배치한다. 사각형 반경은 짧은 변의 절반에 제한한다. 원본 shapeImage처럼 소수 크기의 실제 픽셀 치수는 정수 절삭하고 그리기 경계는 요청 크기를 유지한다. RGBA8 premultiplied sRGB와 기존 100MP/치수 제한을 사용한다. 취소는 할당 전과 그리기/복사/타일화 사이에서 확인하며 Skia 단일 그리기 내부 중간 취소는 제공하지 않는다.

코어 570개 및 기존 WPF 회귀, Release 경고/오류 0 통과. 신규 검사는 도형 내부/외부와 반투명 경계의 premultiplied 불변, 반경 제한, 선의 비율 끝점·둥근 캡과 크기 변경, 입력 오류/초기 취소를 검사한다. Skia와 CoreGraphics의 경계 픽셀 동등성은 실제 Mac 비교 전에는 주장하지 않는다.

## 다음 연결 작업

레이어 속성 및 원본 픽셀 참조로 liveShape를 관리하고 저장/재열기를 연결한다. 현재 ProjectStore는 shape가 있는 원본 프로젝트를 여전히 거부한다. 단순히 미지원 필드를 허용해서 데이터를 읽고 버리지 않는다. 이후 재래스터화·마스크 보존·모델 명령·U 도구/드래그/직관적 설정·Undo/취소·출력/성능 검증을 연결한다. 이번 단계에는 사용자 도구 UI나 새 배포 패키지를 제공하지 않는다. 도형 전체 완료로 계산하지 않는다.
