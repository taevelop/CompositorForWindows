# 문서 탭 구현 현황

2026-10-07: 작업 공간 모델과 MainWindow 탭 UI, 새 문서/열기/저장/복구/닫기를 연결했다.

## 현재 동작

- 새 문서와 프로젝트 열기는 새 탭을 추가한다. 기존 문서의 미저장 편집을 버리지 않는다.
- 탭마다 독립 EditorSession, Undo/Redo, 선택, 수정 여부 및 저장 경로를 유지한다.
- 같은 정규화 경로의 열기는 기존 탭을 선택하며 수정 내용이나 이력을 교체하지 않는다. 디스크에서 다시 읽으려면 해당 탭을 닫고 연다.
- 탭 전환 시 확대/이동 위치와 그룹 접힘 상태를 보존한다. 변형은 확정하고 진행 중 포인터 동작과 크롭 초안은 취소한다.
- 로드 데이터 검증을 통과한 세션만 추가한다. 실패한 열기는 기존 문서와 이력을 보존한다. 복구본은 저장 경로 없는 수정된 새 탭이다.
- 탭의 × 버튼은 미저장 문서에 저장/폐기/취소를 묻는다. 마지막 탭을 닫으면 새 빈 문서를 만든다.
- 앱 종료는 현재 탭부터 나머지 탭을 확인한다. 비활성 탭의 미저장 내용도 해당 탭으로 이동해 확인하며 취소/저장 실패 시 창을 유지한다.
- ValidateSaveDestination을 파일 쓰기 전에 호출하고, 저장 성공 후 RecordSaved를 호출한다. 다른 탭이 연 경로는 저장을 거부한다. 파일 작업 중 busy 상태는 탭 전환/닫기를 차단한다.

## 검증

코어 533개, 확장한 실제 WPF 검사 통과. 탭별 문서/Undo 분리, 확대 위치 복원, 같은 파일 열기의 이력 보존, 탭 닫기 후 실제 디스크 재열기, 닫기 취소/폐기, 비활성 미저장 탭의 앱 종료 취소를 검사했다. 기존 효과/조정/마스크 등의 저장 왕복 검사도 탭 닫기 후 재열기로 변경해 실제 로드 검증을 유지했다.

artifacts/ui-smoke.workspace.png에서 활성 탭의 블루 표시, 문서명/수정 표시와 닫기 버튼을 확인했다. 기존 단일 문서 검사 종료는 모든 테스트 탭을 정리하도록 갱신했다. 물리 마우스나 외부 장비 검증을 대신하지 않는다.

- 브러시/색상/선택 도구 설정은 현재 창 공통이다. 원본의 탭별 도구 설정 범위 대조 및 분리.
- 링크/정션의 실제 파일 동일성 비교, 여러 대형 문서를 연 상태의 메모리/렌더링 성능.
