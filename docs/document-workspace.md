# 문서 탭 구현 현황

2026-10-07: 작업 공간 모델과 MainWindow 탭 UI, 새 문서/열기/저장/복구/닫기를 연결했다.

## 현재 동작

- 새 문서와 프로젝트 열기는 새 탭을 추가한다. 기존 문서의 미저장 편집을 버리지 않는다.
- 탭마다 독립 EditorSession, Undo/Redo, 선택, 수정 여부 및 저장 경로를 유지한다.
- 같은 정규화 경로의 열기는 기존 탭을 선택하며 수정 내용이나 이력을 교체하지 않는다. 디스크에서 다시 읽으려면 해당 탭을 닫고 연다.
- 탭 전환 시 확대/이동 위치와 그룹 접힘 상태를 보존한다. 변형은 확정하고 진행 중 포인터 동작과 크롭 초안은 취소한다.
- 로드 데이터 검증을 통과한 세션만 추가한다. 실패한 열기는 기존 문서와 이력을 보존한다. 복구본은 저장 경로 없는 수정된 새 탭이다.
- 탭의 × 버튼은 미저장 문서에 저장/폐기/취소를 묻는다. 마지막 탭을 닫으면 새 빈 문서를 만든다.
- 앱 종료는 현재 탭부터 나머지 탭을 확인한다. 비활성 탭의 미저장 내용도 해당 탭으로 이동해 확인하며 취소/저장 실패 시 창을 유지한다.
- ValidateSaveDestination을 파일 쓰기 전에 호출하고, 저장 성공 후 RecordSaved를 호출한다. 다른 탭이 연 경로는 저장을 거부한다. 파일 작업 중 busy 상태는 탭 전환/닫기를 차단한다.

## 검증

코어 533개, 확장한 실제 WPF 검사 통과. 탭별 문서/Undo 분리, 확대 위치 복원, 같은 파일 열기의 이력 보존, 탭 닫기 후 실제 디스크 재열기, 닫기 취소/폐기, 비활성 미저장 탭의 앱 종료 취소를 검사했다. 기존 효과/조정/마스크 등의 저장 왕복 검사도 탭 닫기 후 재열기로 변경해 실제 로드 검증을 유지했다.

artifacts/ui-smoke.workspace.png에서 활성 탭의 블루 표시, 문서명/수정 표시와 닫기 버튼을 확인했다. 기존 단일 문서 검사 종료는 모든 테스트 탭을 정리하도록 갱신했다. 물리 마우스나 외부 장비 검증을 대신하지 않는다.

## 잔여

- 탭 재정렬 및 여러 탭의 접근성/오버플로 품질.
- 추가 도구가 구현될 때 해당 도구 설정도 탭별 상태에 포함해야 한다. 전경/배경 팔레트 등 미구현 도구는 별도 잔여 범위다.
- 링크/정션의 실제 파일 동일성 비교, 여러 대형 문서를 연 상태의 메모리/렌더링 성능.
- 그룹 접힘 복원의 복합 실기와 다양한 DPI에서의 탭 조작.
- 실제 Mac 왕복과 별도 Windows PC 검증은 사용자 보류 유지.

배포 확인: artifacts/publish-document-tabs/Compositor.Windows.exe 생성 및 verify-portable.ps1 -Runs 1 통과. 개발 PC의 공유 런타임 차단/공백 경로 검사이며 별도 PC 검증은 아니다.

## 탭별 도구 설정과 단축키

원본 macOS/Compositor/Document/EditorSession.swift의 brushSettings, selectionModeChoice, cropRatioChoice 등 세션별 설정을 대조했다. Windows에서 구현된 도구 선택, 브러시 크기/경도/불투명도/색상, 마스크 농도, 선택 연산/안티앨리어싱/중심 기준, 크롭 비율/스냅을 탭마다 보관한다. 새 탭은 Windows 앱의 초기 기본값으로 시작한다. 이 UI 상태는 문서 수정이나 Undo를 생성하지 않고 .comp에 저장하지 않는다. 크롭 초안은 이전과 같이 전환 시 취소한다.

Ctrl+Tab / Ctrl+Shift+Tab은 다음/이전 탭을 순환하고 Ctrl+W는 현재 문서 닫기를 요청한다. View 메뉴에도 표시했다. 문서 단축키는 텍스트 입력의 일반 편집 단축키보다 먼저 처리한다. 텍스트의 Undo/Delete 처리는 유지한다.

코어 533개 및 확장 WPF 검사 통과. 서로 다른 도구 설정의 복원, 새 문서 기본값, 크롭 초안 비전파, 다음/이전 탭 명령, Ctrl+W 명령의 미저장 취소를 검사했다. 단축키 검사는 실제 창의 명령 처리 함수를 제어된 키/수정키 인자로 호출한 것이며 물리 키보드 입력 검증은 아니다.

배포본 artifacts/publish-tab-tools/Compositor.Windows.exe 및 verify-portable.ps1 -Runs 1 통과. 별도 Windows/Mac 실기는 보류다.

## 많은 탭의 표시와 접근성

탭 갱신 시 기존 버튼을 재사용하여 일반 문서 갱신이 포커스 대상 컨트롤을 제거하지 않게 했다. 긴 문서명은 말줄임하며 전체 경로는 도구 설명에서 확인한다. 활성 문서가 바뀌면 레이아웃 이후 해당 탭을 자동으로 보이게 한다. 활성/미저장 상태를 선택 버튼의 접근성 이름에 포함하고 닫기 버튼도 대상 문서명을 알린다.

코어 533개와 WPF 검사 통과. 10개 탭 추가 후 실제 ScrollViewer의 넘침, 마지막 활성 탭 전체 노출, 첫 탭으로 돌아갈 때 왼쪽 스크롤 복원을 검사했다. 컨트롤 동일성/기존 포커스 유지 및 접근성 이름도 검사했다. 실제 화면 읽기 프로그램과 다양한 DPI 조작은 미검증이며 탭 재정렬은 아직 잔여다.

배포본 artifacts/publish-tab-navigation/Compositor.Windows.exe 생성 및 verify-portable.ps1 -Runs 1 통과. 별도 장비 검증은 보류 상태다.
