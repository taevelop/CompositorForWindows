# Image Size

## 원본과 구현

macOS/Compositor/IO/ImageResizer.swift 및 UI/ImageSizeSheet.swift를 대조했다.

- 캔버스 픽셀 크기가 같으면 해상도만 바꾸고 레이어와 이미지/마스크 참조를 유지한다.
- 픽셀 크기를 바꾸면 각 레이어의 변환된 네 꼭짓점에 가로/세로 배율을 적용하고, 바깥으로 반올림한 경계에 해당 레이어만 재샘플링한다. 회전+비균일 확대의 기울어짐을 픽셀로 보존하며 레이어를 하나로 합치지 않는다.
- 변환된 레이어는 원점·크기를 새 경계로 바꾸고 회전·뒤집기는 픽셀에 적용한다. 그룹/부모·조정·가시성·불투명도·효과 메타데이터는 유지한다.
- 연결 마스크도 같은 좌표로 재샘플링한다. 1×1 균일 마스크는 참조를 유지한다. 그레이스케일·불투명 알파 및 타일 패딩 계약을 보존한다.
- Nearest는 최근접, Smooth는 선형, High는 Skia Catmull-Rom 큐빅으로 구현했다. CoreGraphics의 High와 픽셀 단위 동일성은 검증하지 않았다.
- 출력 캔버스, 모든 변환된 이미지/마스크 크기와 누적 100MP 제한을 래스터 작업 전에 검사한다. 원본은 불변이며 취소·오류 시 세션에 적용하지 않는다. 결과 적용 전 256MiB Undo 보존 한도도 검사한다.
- 변경 시 선택을 해제하고 같은 크기·해상도는 무변경으로 처리한다.

입력 모델은 Pixels/Percent/Inches/Centimeters, 현재 비율 잠금, 해상도 변경, Resample 전환을 구현했다. 재샘플링 중 물리 단위에서 DPI를 바꾸면 인쇄 크기를 유지하며 픽셀 크기를 바꾼다. Resample을 끄면 원래 픽셀 크기로 복원하고 물리 크기·DPI만 편집한다.

## 검증

코어 456개 테스트: 최근접의 정확한 픽셀 복제, 선형/큐빅 경로 구분, 타일 경계, 반투명 경계의 premultiplied alpha, 회전·뒤집기·비균일 확대, 마스크 패딩/균일 마스크, 그룹·조정 보존, 크기 한도/취소, 단일 Undo/Redo, 저장 왕복 및 입력 모델 규칙을 포함한다.

## 남은 연결과 품질

Image > Image size…에 크기/해상도/샘플링 대화상자를 연결했다. Pixels/Percent/Inches/Centimeters, 비율 잠금, Resample 전환과 작업 중 진행 표시를 제공한다. 계산은 백그라운드에서 수행하고 완료 후 원본 문서가 유지되는지 확인한 뒤 한 번의 Undo로 적용한다. 취소/닫기 뒤 늦은 결과는 폐기한다.
현재 각 레이어의 입력/출력 비트맵을 전체 크기로 만든다. 큰 문서의 피크 메모리·지연 측정과 개선이 필요하며, Skia 한 번의 DrawImage 호출 도중에는 즉시 취소되지 않는다. 타일별 취소와 반환 전 취소 검사로 늦은 결과 적용은 막는다.
원본 코드 일부는 크기 변경 시 효과 필드를 누락하지만 Windows에서는 데이터 손실을 피하도록 효과 설정을 보존한다. 실제 Mac 비교는 보류 항목이며 샘플링 품질의 동등성을 주장하지 않는다.
현재 실행 패키지는 artifacts/publish-image-size/Compositor.Windows.exe이다.

./build.ps1 -Test: 경고/오류 0, 456개 코어 테스트 및 기존 실제 WPF 회귀 검사 통과. 실제 WPF에서 메뉴 실행, 잘못된 입력, 비율 잠금, 리샘플링 적용, DPI만 변경 시 픽셀 참조 보존, 단일 Undo/Redo, 계산 중 취소와 늦은 결과 폐기를 검사한다.

Image Size UI 실제 WPF 검증 및 artifacts/ui-smoke.image-size.png 화면 점검 통과.
