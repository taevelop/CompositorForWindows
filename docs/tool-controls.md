# 도구 막대와 색상 선택 UI

2026-10-06. 사용자 피드백에 따라 Windows 초기 이식의 숫자/드롭다운 중심 도구 막대를 변경했다. Windows 자체의 UI 제약이 아니라 이전 WPF 구현에서 원본의 시각적 컨트롤을 생략한 차이다. `macOS/` 소스는 수정하지 않았다.

## 원본 Mac과 비교

| 항목 | Mac 원본 | 이전 Windows | 이번 Windows |
|---|---|---|---|
| 도구 선택 | 세로 아이콘 버튼, 브러시/지우개 분할 선택 | 드롭다운 | Move / Brush / Eraser / Hand 직접 선택 버튼, 선택 상태 강조 |
| 크기 | 숫자 입력, 방향키 증감 | 숫자 입력 | 1–2000px 슬라이더 + 숫자 입력 |
| 경도·불투명도 | 슬라이더 + 숫자 입력 | 숫자 입력 | 슬라이더 + 숫자 입력 |

## 사용 방식

- V/B/E/H 단축키와 도구 버튼을 함께 사용할 수 있다. Move/Hand에서는 브러시 설정을 숨기고 해당 도구의 조작 안내를 표시한다.
- Size, Hardness, Opacity를 슬라이더 또는 숫자로 조절한다. 슬라이더는 클릭/드래그 및 방향키로 조절하며 숫자는 Enter 또는 포커스 이동 시 확정한다. 범위 밖 숫자는 제한 범위로 보정하고, 잘못된 입력은 마지막 정상 값으로 복원한다. Enter 후 캔버스로 포커스를 돌린다.
- 색상 견본을 누르면 선택 창이 열린다. 색상 영역은 좌우 채도·상하 명도를 조절하고, 아래 슬라이더는 색조를 조절한다. 기본 팔레트, 현재/새 색상 비교, HEX 직접 입력을 지원한다. 색상 영역의 방향키는 1%, Shift+방향키는 10%씩 조절한다.
- Use color로 적용한다. Cancel/Esc/창 닫기는 기존 브러시 색을 유지한다. 잘못된 HEX 입력 중에는 적용할 수 없다. 투명도는 색상 대신 브러시 Opacity로 조절한다.
- 마스크의 Brush 모드에서는 색상 대신 Mask gray와 Black · Hide / White · Reveal을 표시한다. 지우개는 기존대로 마스크를 숨긴다.
- 설정 변경은 이미지 편집 이력을 만들지 않는다. 실제 스트로크의 Undo/Redo 동작은 유지한다.
- 최소 창 너비 1000 DIP에서 옵션 그룹이 줄바꿈한다. Fit과 100% 버튼을 직접 제공한다.

이번 범위는 상단 도구 막대다. 레이어 변환·합성 모드와 개별 효과/조정 창의 입력 방식은 별도 개선 대상이다. 색상 선택기는 모달 창이며 Mac처럼 창을 열어둔 채 캔버스에서 색을 추출하는 기능은 아직 없다.

## 검증

`build.ps1 -Test`로 Release 빌드(경고·오류 0), xUnit 260개 및 기존 WPF 스모크를 통과했다. 추가 검사는 `artifacts/ui-smoke.tools.json`에 기록한다: 4개 도구 선택, 문맥별 설정, 숫자/슬라이더 양방향 동기화, 범위/잘못된 값 처리, 문서/이력 불변성, 색상 적용/취소, HEX 검증, 색조·키보드 조절, RGB/HSV 왕복, 마스크 프리셋, 최소 너비 배치.

툴바와 색상 창의 렌더링 이미지를 확인해 어두운 배경의 글자 대비와 선택 표시를 보정했다. 배포본은 `verify-portable.ps1 -Runs 1`로 복사 실행과 패키지 내부 CLR·Skia·C DLL 로딩을 다시 검증한다. 이전 마우스·DPI 실기 결과는 이전 UI에 대한 기록이며, 새 UI의 사용성은 사용자의 추가 확인 대상이다.
