# Windows 실사용 안정화 체크리스트

기준: `fea2315` 이후 Windows MVP. 이번 작업은 입력·히스토리·저장/복구·다층 성능의 안정화이며, 마스크 기능은 다음 단계다.

`[x]`는 이번 실행에서 검증한 항목, `[ ]`는 미검증 항목이다. 자동 입력 경로 검증과 물리 장치 실측은 구분한다.

## 편집 및 입력

- [x] PNG/JPEG 가져오기 → 다층 편집 → 브러시/지우개 → Undo/Redo → 저장 → 새 세션에서 열기 → PNG/JPEG 내보내기
- [x] 변화 없는 클릭·동일 속성 적용은 수정 표시나 Undo를 만들지 않으며 Redo를 유지
- [x] 이동 후 원래 위치로 돌아온 드래그는 변화 없는 편집으로 처리
- [x] Undo/Redo와 편집 취소 후 선택된 레이어가 유효하며 저장된 수정 상태 복원
- [x] 왼쪽 드래그 중 오른쪽/가운데 버튼 입력이 편집을 완료하거나 pan으로 전환하지 않음
- [x] Esc·캡처 상실·창 비활성화는 미완료 편집을 취소
- [x] Hand/pan도 Esc로 취소되고 입력 캡처 해제
- [x] 드래그 중 휠 확대/축소로 스트로크 좌표가 변경되지 않음
- [ ] 실제 마우스로 창 전환·창 경계 밖 드래그·빠른 버튼 조합 검증

## 파일 및 복구

- [x] 손상·미지원 프로젝트를 열어도 현재 문서와 이력이 유지됨
- [x] 저장 실패 후 기존 파일과 수정 표시 유지, 임시 파일 정리
- [x] 복구 사본을 변경하지 않고 열고 다른 `.comp` 경로로 저장 가능
- [x] 기존 원본과 복구 사본이 모두 있으면 자동 덮어쓰기하지 않음
- [x] 같은 프로젝트 동시 저장 차단
- [x] 미저장 종료에서 저장/버리기/취소, 저장 실패 시 창 유지
- [ ] 저장 중 실제 프로세스 강제 종료 및 재시작 검증

## 성능 및 표시

- [x] 4K 문서 1/3/6개 레이어에서 입력·합성·종료·메모리 측정
- [x] 반복 스트로크 및 Undo/Redo 후 보존 메모리·이력 한도 측정
- [x] 증분 합성과 전체 렌더링의 픽셀 일치
- [x] 100%/150%/200% 배율에 해당하는 렌더 크기에서 픽셀 일치
- [ ] 실제 다중 모니터 이동, Windows DPI 전환, 펜 입력 검증

## 다음 단계 진입 조건

자동화 가능한 입력·문서·저장 회귀 검증을 통과하고 다층 성능 결과와 남은 실기 항목을 기록한다. 미검증 항목을 완료로 표시하지 않는다. 그 후 레이어 마스크를 별도 기능 단위로 구현한다. 2026-09-23 구현 결과는 [레이어 마스크 검증](layer-masks.md)에 기록했다.

검증: xUnit 51개 및 숨김 WPF 경로 통과. 4K 6개 레이어 갱신 p95 최대 30.5ms. 종료 확인의 저장/버리기 분기는 주입 응답과 저장 결과로 검증했으며, 실제 창 종료는 취소/clean Close 경로에서 검증했다. 측정 조건과 한계는 [안정화 검증 결과](windows-stability-validation.md)를 참고한다.
