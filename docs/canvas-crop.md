# 크롭 도구

원본 macOS/Compositor/Document/Crop.swift, Document/LayerTransform.swift 및 IO/CanvasResizer.swift를 대조했다.

## 구현

- 정수 픽셀 프레임 생성·이동, 8개 핸들 크기 변경, 고정 비율 및 중심 기준 크기 변경.
- 캔버스 크기와 모든 레이어의 절대 위치를 변경하며 원본 이미지와 연결 마스크의 픽셀은 공유한다. 캔버스 밖 픽셀을 삭제하지 않는다.
- 그룹 자식의 좌표를 중복 이동하지 않는다. 효과·조정·회전·뒤집기·레이어 메타데이터를 보존한다.
- 확정 시 선택을 해제한다. 문서 검증을 통과한 변경만 적용하고 Undo/Redo로 원래 문서와 선택을 복원한다.
- 크기·좌표·100MP 제한 및 비정상 수치를 검사한다.

## 검증

./build.ps1 -Test: 코어 테스트 429개 및 실제 WPF 검사 통과. 크롭 결과와 원래 렌더링의 해당 영역 일치, 저장/재열기 후 캔버스 밖 픽셀과 마스크 보존, 재확장, Undo 공유 및 실패 시 원본 보존을 검사한다.
핸들 8개의 최초 위치 유지, 중심 유지, 반대편 경계 통과, 비율 및 좌표 제한을 검사한다.

## 사용법과 UI

- 도구 레일의 Crop 또는 C로 선택한다. 드래그로 프레임 생성, 내부 드래그로 이동, 8개 핸들로 크기를 조절한다.
- Free / Original / 1:1 / 4:3 / 16:9 비율을 선택한다. Alt 드래그는 중심을 유지한다.
- Snap edges는 캔버스와 표시 중인 이미지 레이어의 경계에 6 화면 픽셀 이내로 접근할 때 맞춘다. 고정 비율 생성/크기 변경에는 스냅을 적용하지 않으며 이동에는 적용한다.
- Apply/Enter로 한 번의 Undo에 확정하며 캔버스를 화면에 맞춘다. Cancel/Esc와 도구 전환은 초안을 버린다.
- 마우스 캡처 상실/창 비활성화는 진행 중인 드래그 이전 초안으로 복원한다. 문서 변경 시 오래된 초안을 버린다.
- 삼분할 안내선, 바깥 영역 음영, 크기 표시, 방향별 커서를 제공한다. 출력 이미지에는 오버레이가 들어가지 않는다.

## 추가 검증과 잔여

실제 WPF에서 생성·이동, 핸들 8개의 경로, 다른 버튼 거부, 캡처 상실, 비율·Alt, 캔버스 스냅, Enter/Esc, 도구 전환, 문서 변경, Undo/Redo를 확인했다. 9개 도구의 제목/캔버스 위치 검사와 화면 캡처 확인도 통과했다.
전체 선택·크롭 영역에는 자동 스크롤, 선택 픽셀 회전/크기 변경, 선택 성능 측정 등의 잔여가 있다. 가이드와 전역 Snap To 대상 설정은 후속 작업 공간 범위이며 현재 크롭은 canvas/layer edges 체크박스를 제공한다. [Canvas Size](canvas-size.md)의 기준점·확장 배경 대화상자는 연결했다. 이미지 리샘플링용 Image Size는 아직 없다.
실제 Mac 및 별도 Windows PC 검증은 사용자 지시로 보류한다. 전체 Windows 전환 완료로 계산하지 않는다.
