# 크롭 연산 기반

원본 macOS/Compositor/Document/Crop.swift, Document/LayerTransform.swift 및 IO/CanvasResizer.swift를 대조했다.

## 구현

- 정수 픽셀 프레임 생성·이동, 8개 핸들 크기 변경, 고정 비율 및 중심 기준 크기 변경.
- 캔버스 크기와 모든 레이어의 절대 위치를 변경하며 원본 이미지와 연결 마스크의 픽셀은 공유한다. 캔버스 밖 픽셀을 삭제하지 않는다.
- 그룹 자식의 좌표를 중복 이동하지 않는다. 효과·조정·회전·뒤집기·레이어 메타데이터를 보존한다.
- 확정 시 선택을 해제한다. 문서 검증을 통과한 변경만 적용하고 Undo/Redo로 원래 문서와 선택을 복원한다.
- 크기·좌표·100MP 제한 및 비정상 수치를 검사한다.

## 검증

./build.ps1 -Test: 코어 테스트 426개. 크롭 결과와 원래 렌더링의 해당 영역 일치, 저장/재열기 후 캔버스 밖 픽셀과 마스크 보존, 재확장, Undo 공유 및 실패 시 원본 보존을 검사한다.
핸들 8개의 최초 위치 유지, 중심 유지, 반대편 경계 통과, 비율 및 좌표 제한을 검사한다.

## 남은 연결

아직 사용자 크롭 도구로 노출하지 않았다. 오버레이·8개 핸들 입력, 비율 선택, 캔버스/레이어 가장자리 스냅, Apply/Enter·Cancel/Esc, 도구 전환 및 캡처 상실 검증을 이어간다.
기존 실행 패키지는 artifacts/publish-clipboard/Compositor.Windows.exe이며 이번 연산 기반만으로 새 패키지를 배포하지 않는다.
전체 선택·크롭 영역 또는 전체 Windows 전환 완료로 계산하지 않는다.
