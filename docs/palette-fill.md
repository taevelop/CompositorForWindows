# 팔레트 채우기

2026-10-07: Edit > Fill foreground color / Fill background color 연결. 기존 색상표의 전경/배경색을 사용한다. 마스크는 회색 농도와 그 반대 값을 사용한다. 선택이 없으면 캔버스 영역, 선택이 있으면 선택 농도 범위, 명시적 빈 선택이면 무변경이다. 브러시 크기/불투명도와 독립적인 불투명 색 채우기다.

원본 SelectionEdits.fillSelection와 BrushStroke.paintCanvas/init을 대조했다. 이미지의 원본 격자에서 캔버스 역변환 경계와 원래 영역의 합집합으로 확장한다. RasterReframe을 통해 기존 픽셀의 문서 좌표 및 연결 마스크 위치를 보존한다. 마스크 자체 채우기는 기존 격자를 확장하지 않는다. 그룹/이미지 없는 조정은 직접 이미지 채우기를 거부하고 조정 마스크는 지원한다. 선택/캔버스 제한은 현재 Windows의 픽셀 중심 샘플 규칙을 사용한다.

불변 타일로 계산 후 한 번의 Undo로 적용한다. 계산은 Work의 worker에서 수행하며 UI는 busy 상태로 보호하고, 완료 시 캡처한 문서가 여전히 현재 문서인지 확인한다. 취소 토큰 API와 Undo 예산 검사는 있으나 사용자 취소 버튼은 아직 없다.

검증: 코어 552개 및 WPF 회귀 통과. 작은 이미지의 캔버스 확장, 원본 불변, 같은 색 무변경, Undo/Redo, 마스크 이미지/변환 보존, 선택/빈 선택, 사전 취소, 실제 팔레트 전경·배경 명령과 마스크 반대 농도를 검사했다.

잔여: 회전·뒤집기·소수 캔버스 경계의 Mac 안티앨리어싱 대조, 페더/타일 경계 및 저장 후 재열기 전용 검사, 대형 채우기 예산 사전 검사/취소 UI/성능, 단축키. 편집 가능한 텍스트의 원본 재색칠은 텍스트 구현 단계에서 연결한다. 독립 배치 마스크는 전체 전환 잔여이며 현재는 연결 마스크만 지원한다. 이 단계는 버킷의 연속 영역 채우기나 그라디언트 구현이 아니다.
배포: artifacts/publish-palette-fill 생성 및 격리 WPF 실행 1/1 통과. 실제 Mac/별도 PC 검증 보류 유지.
