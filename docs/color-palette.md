# 전경·배경 팔레트

2026-10-07: 원본 Document/ColorPalette.swift의 전경/배경 교환과 기본값 복원 규칙을 대조했다.

- 도구 모음에 겹친 전경/배경 색상표를 표시하고 각각 기존 색상 선택창을 연다.
- X와 교환 버튼은 전경/배경 색상을 바꾼다. D와 초기화 버튼은 검정/흰색으로 복원한다. 텍스트 입력 중에는 입력 컨트롤의 단축키를 유지하고 Ctrl+X/Ctrl+D는 기존 잘라내기/선택 해제다.
- 마스크 편집에서는 그림 색상을 보존한다. X는 현재 회색 농도를 100-값으로 바꾸고 D는 검정(0%)으로 되돌린다. 색상표는 현재 농도와 반대 농도를 표시한다. 원본의 흑백 토글을 기존 Windows 연속 회색 슬라이더에 맞게 확장한 동작이다. RGB 색상 선택은 마스크 편집에서 비활성화한다.
- 배경색도 탭별 도구 설정으로 저장/복원한다. 새 문서의 배경색은 흰색이다. 팔레트 변경은 문서를 수정하거나 Undo를 만들지 않으며 .comp에 저장하지 않는다.
- Canvas Size의 Background 채우기는 현재 문서의 배경 팔레트를 사용한다. Transparent/Foreground/Black/White/Custom은 유지한다.

검증: WPF에서 전경/배경 교환과 표시, 초기화, 문서/Undo 불변성, 마스크 농도 및 그림 팔레트 보존, 탭별 전경/배경 복원, Canvas Size 배경 채우기 옵션을 검사한다. 기존 타원 선택 검사에서 한 차례 간헐 실패가 관찰됐고 후속 실행은 통과했으나 원인 해결로 간주하지 않는다.

잔여: 스포이트의 합성/현재 레이어 샘플링, Gradient Map 신규 생성의 전경/배경 초기값 연결, 전역 배경색을 사용하는 후속 채우기/그라디언트 도구, 실제 키보드/색상표 조작 실기. 별도 Windows/Mac 검증은 사용자 보류 유지.
