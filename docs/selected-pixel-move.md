# 선택 픽셀 이동·복제

2026-10-06: 선택 픽셀 이동·복제를 문서 이력과 캔버스 입력에 연결했다. 클립보드·선택 변형·대형 문서 성능은 별도 잔여다.

## 사용

선택 도구(사각형/타원/자유/다각형 올가미)에서 선택 내부를 대상으로:
- Ctrl-drag: 선택 픽셀 이동.
- Ctrl+Alt-drag: 원본 픽셀을 남기고 복제.
- Ctrl+방향키: 1px 이동, Ctrl+Shift+방향키: 10px 이동.
- 드래그 중 Shift: 한 축 제한. Esc·캡처 상실·도구 전환: 취소.
- Ctrl 없이 내부 드래그/방향키는 선택 윤곽만 이동한다.

이미지 편집 대상만 지원한다. 마스크·그룹·조정 레이어·숨긴 레이어는 거부한다. 선택이 없거나 빈 선택, 선택 아래 투명 픽셀만 있는 경우는 편집을 시작하지 않는다.

## 구현

- SelectedPixelTransfer.Lift: 문서 좌표 선택 농도를 소스 픽셀 중심에 적용해 선택 픽셀과 잘라낸 원본을 만든다.
- CompositeOnto: 처음 추출한 픽셀을 CutSource 또는 원본 위에 premultiplied source-over로 합성한다. 이전 미리보기 위에 누적하지 않는다.
- 정수 오프셋은 정확한 픽셀 복사, 소수 오프셋은 Smooth의 bilinear 또는 High의 Catmull-Rom cubic 샘플링을 사용한다. 이웃 타일을 함께 참조해 경계 이음새를 막는다.
- RasterReframe: 픽셀 범위 변경 시 원본의 문서 좌표 위치를 유지한다. 이미지의 새 영역은 투명, 마스크는 원본처럼 흰색이다. 1×1 균일 마스크도 원래 소스 영역의 농도를 유지한다.
- SelectionPixelMoveEdit: 문서 이동량을 정수로 반올림하고 레이어 픽셀 좌표로 변환한다. 원래 소스와 역변환한 캔버스의 합집합을 허용 범위로 삼고 이동한 픽셀에 필요한 범위만 확장한다.
- 확장 전 소스/마스크 각각 100MP 예산을 검사한다. 미리보기와 확정은 문서 유효성 및 256 MiB Undo 제한을 확인한다.
- 확정 시 알파가 있는 경계로 자르고 마스크·레이어 변환을 함께 재배치한다. 픽셀과 이동한 선택은 같은 트랜잭션으로 확정한다.
- 원점으로 돌아오면 원본 참조와 Redo를 유지한다. 오류/취소는 원본 문서로 복구한다.
- 256px에 맞는 재배치는 기존 타일을 공유한다. 회전·뒤집기·레이어 속성은 유지한다.

## 원본 대조 및 한계

macOS/Compositor/Document/BrushStroke.swift의 liftSelection, moveLifted, transform(for:), BrushCommit.expandMask, EditorSession+Brush.swift 및 SelectionEdits.swift를 대조했다.

CoreGraphics high 보간과 Windows cubic의 실제 결과 동등성은 증명하지 않았다. 정수 이동은 정확하게 검증했고 소수 이동은 타일 이음새·premultiplied 불변성을 검증했다. 실제 Mac 비교는 보류한다.

현재 선택 추출·이동 합성·최종 알파 경계 검사는 CPU 동기 경로다. 4K 대형 선택의 포인터 지연/메모리/확정 시간 검증과 최적화가 남아 있다. 레이어 크기 최소 1px 등 기존 모델 제한은 원본과 같이 유효성 검사한다.

## 검증

./build.ps1 -Test: Release 경고/오류 0, 403개 코어 테스트 및 실제 WPF 회귀 검증 통과.

- 픽셀 추출/잘라내기, 투명 범위, 반투명 합성/복제, 두 샘플러의 타일 경계, 반복 미리보기 불변성, 미변경 타일 공유.
- 정렬/비정렬 프레임, 회전/양축 뒤집기, 균일 마스크 확장, 레이어 밖 이동의 좌표 보존.
- 단일 Undo/Redo, 0거리 무변경/Redo 보존, 취소/잘못된 값 복구, 편집 대상 제한, 확장 예산 초과.
- 이동한 픽셀/변환/마스크의 .comp 저장 재열기. 선택은 원본처럼 저장하지 않는다.
- WPF 실제 경로의 Ctrl 이동·Ctrl+Alt 복제·취소·방향키 이동·Undo 및 도구 위치 유지.

## 남은 연결

1. 선택 복사/잘라내기/붙여넣기 및 외부 Windows 클립보드 알파·포맷.
2. 선택 픽셀 크기/회전 변형.
3. 캔버스 밖 드래그 자동 스크롤, 큰 선택 성능, 원본 실기 비교.
4. 크롭과 캔버스/레이어 크기 변경의 공통 범위 재배치.

실행 패키지: artifacts/publish-pixel-move/Compositor.Windows.exe. 기존 패키지는 보존한다. 격리 실행은 현재 개발 PC 검사이며 별도 Windows PC 검증을 대체하지 않는다.
