# 레이어·선택 픽셀 변형

원본 Document/FloatingSelection.swift의 beginSelectionTransform, floatingSelectionTransform, FloatingMerge를 대조했다.

## 구현

SelectionTransformPixels는 문서 좌표에서 선택한 이미지 픽셀과 원본을 준비하고, 이동·회전·크기·뒤집기 설정으로 결과 문서를 계산한다. 각 결과는 원본 선택 픽셀에서 다시 계산하여 반복 미리보기의 재샘플링 손실을 누적하지 않는다.

변형된 픽셀은 원래 레이어의 역변환으로 소스 격자에 합성한다. 바깥 영역은 원본처럼 문서 경계 상자 → 소스 경계 상자로 환산하여 레이어를 확장한다. 마스크의 기존 영역은 유지하고 새 여백은 흰색으로 채운다. 회전·뒤집기·그룹 부모·불투명도·효과 설정은 보존한다. 선택 윤곽은 같은 변환을 적용하며 페더 수치는 유지한다.

초기 변형과 정확히 같은 설정은 원본 Document 참조를 그대로 반환한다. 부드러운 선택 경계의 절단/재합성으로 생기는 무변경 이음을 방지한다. 현재 마스크 대상·그룹·조정·숨긴 레이어는 선택 픽셀 변형에서 제외한다.

출력 레이어/문서 이미지·마스크 예산을 할당 전에 검사하고 결과의 Undo 보존 한도도 검사한다. 원본은 불변이며 취소/오류 시 세션에 결과를 적용하지 않는다.

## 검증

코어 474개 테스트에 원점 복원·미리보기 누적 방지·이동/뒤집기/확대/회전·선택 윤곽·premultiplied alpha·흰 마스크 확장·잘못된 대상/크기/취소 검사를 포함했다. 회전/뒤집기가 있는 원본 레이어로의 재합성, 그룹/효과 보존, 한 번의 Undo/Redo와 프로젝트 저장 왕복도 확인한다.

## 연결 잔여

Ctrl+T와 Layer > Transform layer / selection에 핸들/회전/비율/뒤집기 UI를 연결했다. 아래 UI 사용법과 검증 범위를 참조한다. 원근/왜곡, 독립 마스크 변형 및 다중 레이어 변형은 별도 후속 범위다.

현재 준비 단계는 기존 CPU 복사 렌더를 사용하며 결과 합성은 전체 레이어 비트맵을 만든다. 대용량 지연·피크 메모리와 취소 응답성 개선은 잔여다. Skia 샘플링과 실제 Mac 결과의 픽셀 단위 동등성은 검증하지 않았다. 원본 일부 합성 코드의 효과 누락은 재현하지 않고 Windows는 효과를 보존한다.

실행 패키지: artifacts/publish-transform/Compositor.Windows.exe.

./build.ps1 -Test: 경고/오류 0, 코어 474개 및 기존 실제 WPF 회귀 검사 통과.

## 핸들 연산과 편집 상태

TransformDrag는 원본 LayerTransform.swift의 이동/회전/8개 크기 핸들 규칙을 구현한다. 회전한 좌표에서 반대편 기준점을 고정하고 Alt 중심 조절, Shift 축 제한/15도 회전, 비율 잠금의 Shift 임시 반전, 반대쪽 경계를 넘을 때 뒤집기를 처리한다. 핸들 위치는 이미지 뒤집기와 무관한 기하 좌표를 사용한다. 포인터가 움직이지 않으면 원본 변형 참조를 그대로 반환한다.

LayerTransformEdit는 전체 이미지 레이어 또는 선택 픽셀의 미리보기·확정·취소를 한 트랜잭션으로 관리한다. 잘못된 미리보기는 취소하고 원본을 복원한다. 선택이 캔버스 밖에 있어 추출할 수 없을 때 전체 레이어 변형으로 넘어가지 않고 명시적으로 거부한다. 연결 마스크 대상에서는 기존 레이어와 마스크가 함께 변형된다.

컨트롤러는 단일 이미지 레이어/선택 픽셀과 그룹을 지원한다. 다중 레이어·독립 마스크·왜곡은 여전히 후속 범위다. Ctrl+T, 시각적 핸들/회전/수치·슬라이더 UI와 도구 전환 규칙을 연결했다.

핸들/편집 상태 검증: ./build.ps1 -Test 경고/오류 0, 코어 488개와 기존 실제 WPF 회귀 검사 통과. 회전 핸들 8개·반대편/중심 기준점·뒤집기·비율·이동축·회전 스냅·무변경/취소/오류/Undo를 검사했다.

## UI 사용법과 검증

- Ctrl+T 또는 Layer > Transform layer / selection으로 시작한다. 활성 이미지 레이어의 선택이 있으면 선택 픽셀을, 없으면 전체 레이어를 변형한다.
- 사각형 내부 드래그는 이동, 8개 사각 핸들은 크기 조절, 상단 원형 핸들은 회전이다. 회전 방향을 반영한 커서를 표시한다.
- Ratio 체크와 Shift 임시 전환, Alt 중심 기준, Shift 이동축/15도 회전 제한을 지원한다. 방향키는 1px, Shift+방향키는 10px 이동한다.
- Scale %와 Rotation은 슬라이더 및 정확한 숫자 입력을 제공한다. Scale은 초기 픽셀/레이어 크기를 기준으로 중심을 유지하며 양축 크기를 바꾼다. Flip H/V는 해당 축 뒤집기다.
- 마우스를 놓으면 변형 모드를 유지한다. Apply/Enter로 여러 번의 조절을 한 Undo에 확정하고 Cancel/Esc로 원본을 복원한다. 숫자 입력의 Enter는 해당 수치를 먼저 적용하고 캔버스로 포커스를 돌린다.
- 도구/레이어 전환 및 저장은 현재 변형을 확정한다. 캡처 상실/창 비활성화는 진행 중인 드래그만 직전 초안으로 복원한다. 중간 버튼 이동과 휠 확대/축소로 작업 화면을 조절할 수 있다.
- 실제 WPF에서 핸들 8개/방향 커서/회전 핸들, 슬라이더·뒤집기, Enter/Esc, 선택 변형 Undo/Redo, 도구/레이어 전환, 캡처 상실, 중간 버튼 이동, 제목과 캔버스 위치 고정을 검사했다. artifacts/ui-smoke.transform.png를 직접 확인했다.

선택 픽셀의 미리보기 합성은 현재 UI 스레드에서 동기 계산한다. 큰 선택/레이어에서 지연이 생길 수 있으며 비동기·가벼운 미리보기 경로와 피크 메모리 측정은 남아 있다. 다중 레이어·왜곡·독립 마스크 변형과 이동 스냅 가이드도 후속 범위다.

UI 최종 검증: ./build.ps1 -Test 경고/오류 0, 488개 코어 테스트와 확장한 실제 WPF 검사 통과. verify-portable.ps1 -Runs 1 격리 실행 통과. 개발 PC의 공백 경로·제한 PATH·공유 런타임 미사용 검사이며 별도 Windows PC 실기 검증을 대체하지 않는다.

## 그룹 변형

그룹을 선택하고 Ctrl+T를 누르면 보이는 이미지 자식의 경계로 같은 핸들과 슬라이더를 사용한다. 중첩 그룹의 이미지도 포함하며 숨긴 이미지와 조정 레이어는 제외한다. 그룹 자체의 저장 변형은 유지하고 각 자식의 위치·크기·회전·뒤집기를 원본 기준으로 계산한다. 이미지·연결 마스크·효과 데이터는 공유한다. 픽셀 선택이 있어도 그룹 전체 규칙을 사용한다.

원본 LayerTransform.following처럼 회전된 자식을 비균일 확대할 때 생기는 기울어짐 성분은 버린다. 완전한 아핀/원근 변형 지원을 뜻하지 않는다. 잘못된 자식 크기나 문서 한도 초과는 전체 편집을 취소하며 일부 자식만 변경하지 않는다. 빈 그룹은 시작 전에 거부한다.

코어 495개와 실제 WPF 검사에서 그룹 경계·숨긴 자식 제외·회전/뒤집기·원본의 비균일 확대 규칙·저장 왕복·단일 Undo/취소를 검증했다. 실행 패키지는 artifacts/publish-group-transform/Compositor.Windows.exe이다.

그룹 배포 검증: verify-portable.ps1 -Runs 1 통과. 개발 PC의 격리 실행이며 보류한 별도 Windows/Mac 실기 검증은 미완료로 유지한다.
