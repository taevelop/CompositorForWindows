## 편집 트랜잭션 기반

2026-10-07: GradientEdit가 시작 문서/레이어/마스크 대상을 캡처해 세션 트랜잭션을 시작한다. 설정 변경마다 원본에서 비동기 계산하며 직전 요청을 취소한다. SemaphoreSlim으로 연산을 직렬화해 동시 대형 이미지 작업을 막고 최신 요청만 미리보기에 적용한다. CommitAsync는 마지막 미리보기를 기다린 뒤 한 번의 Undo로 확정하며 대기 중 설정 변경을 거부한다. Dispose는 자신이 소유한 미리보기만 취소하고, 외부에서 문서를 교체한 경우 그 문서를 덮어쓰지 않는다.

코어 564개 통과: 반복 설정 변경의 원본 기준 결과, 단일 Undo/Redo, 대기 중 취소, 최신 요청 우선, 짧은 선 원본 복원, 외부 문서 교체 후 결과 폐기, 확정 중 설정 변경 차단. 클래스는 UI 스레드 소유이고 불변 픽셀 계산만 worker에 보낸다. 아직 G 도구/캔버스 입력/설정 패널에는 연결하지 않았으며 실제 UI 전환·저장 확정/취소 검사와 대형 미리보기 측정은 다음 단계다.
편집 기반 최종 검증: 경고/오류 0, 코어 564개 및 기존 WPF 회귀 통과. 사용자 도구 UI가 아직 없어 새 배포 패키지는 생성하지 않았다.

## G 도구 UI 1차 연결

2026-10-07: G 도구 레일/단축키, 문서 좌표의 드래그 선과 양 끝점 핸들, 선형/방사형·투명 전환·반전·불투명도 슬라이더와 정밀 입력을 연결했다. Apply/Cancel 및 Enter/Esc로 확정/취소하고 도구 선택 전환은 pending 그라디언트를 확정한다. 0.5픽셀 미만 드래그는 취소한다. 화면의 선과 핸들은 확대와 독립된 두께/크기로 표시한다. 기본 팔레트 색상과 마스크 회색을 읽는다.

WPF 검사: 실제 도구 선택/패널, 확대 화면 좌표의 드래그 결과, 끝점 이동, 단일 Undo와 취소, 도구별 제목/캔버스 정렬. 초기 화면 검사에서 기본 시스템 색상/슬라이더를 발견해 기존 Ink 및 EditorSlider 다크 테마로 맞추었다.
